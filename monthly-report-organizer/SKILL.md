# 月报整理助手

## 触发条件
用户提供了本月的工作记录，需要整理成月报格式。

## 输入要求
1. 上月月报模板（可选，用于参考格式）
2. 本月工作记录（零散的工作内容）

## 输出格式要求

**字数控制：600-800字（非空白字符），突出成效、讲清楚内容即可**

**格式规范：**
1. 使用纯文本格式，不使用markdown
2. 一级分类用数字+顿号：1、2、3、
3. 二级分类用数字+括号：1）2）3）
4. 同一级的多个事项用分号分隔，不换行（不使用三级列表）
5. 每个要点简洁明了，保留关键信息，突出成效
6. 项目名称加冒号后直接跟内容（如"金卡达：沟通顺利，推进签约"）
7. 优先保留：已完成的成果、关键数据、重要决策
8. 精简删除：重复表述、过程描述、次要细节

**示例格式（约650字）：**
```
1、台州项目推进
1）项目管理
参与经信局周会，沟通研发问题；组织组内周会明确分工；明确合同完成情况，重点推进普汇、飞达、精力、中邦交付
2）智能体应用开发
中邦下单：设计数据回流思路，定位ocr错误和转化逻辑问题，设计置信度评判方法；科马bom：工期评估完成，客户有签约意向；问数v2效果调优中；token调用统计初步完成，能按企业统计；紧急修复星海智文配置问题、qwen3掉线
3）需求评估与客户走访
铭岛铝业：业务流程对接清楚，需带demo汇报；金卡达：沟通顺利，计划获取数据测试
4）基础设施与团队
qwen3.5-397b部署完成，输出速度50-60tokens/s；实习生分工明确

2、企微项目支撑
1）进度沟通与研发
企微二期卡点不在我们，推进数据传输和模型提升；意图识别安全围栏待推进
2）结项准备
软著待整合，专利补充技术方案；和客经细化需求，合作顺畅

3、科创项目推进
路桥项目推广整合为科创：平台升级往省级方向；智能体结合永康、莲都调研需求；完成企微子项目挂账；加计扣除材料对接

4、其他
能力产品化：维护AI产品方案报价；培训：参加人工智能平台考试
```

## 月报结构框架

### 标准分类（按项目/领域）

1. **工业项目**
   1）路桥项目完善
      - 已签约项目验收（成效优先）
      - 现有智能体优化（纵向深化）
      - 新智能体应用demo（横向拓展：具体客户+进展+成效）
      - 智能体运营（bug修复、功能优化）
   2）台州市级平台升级
      - 路桥平台优化
      - 方案沟通、领导汇报结果
      - 科创立项
   3）其他地市复制
      - 丽水莲都、湖州长兴、金华永康、临海、黄岩等（简要概括每个地市进展）

2. **客经项目**
   1）企微二期验收（数据传输、模型效果、材料准备）
   2）新一期数字人项目（立项、demo）

3. **公客项目**（如有）

4. **其他事项**（团队沟通、考评、工具使用等）

## 整理规则

1. **分类归纳**：将工作按上述框架归类
   - 优先按项目归类，其次按工作性质
   - 跨项目的工作按主要归属分类
   - 分类会随业务变化调整（如从"台州项目/企微项目/科创项目"演变为"工业项目/客经项目/公客项目"）

2. **内容精简**：
   - 去掉口语化表达，合并同类事项
   - 保留关键信息：做了什么、进展如何、成效/问题
   - **重点突出成效**：如"客户认可流程和验收标准"、"方案基本认可"
   - 问题和风险也要体现：如"未达合同要求"、"效果不确定被叫停"

3. **字数控制**：
   - 目标600-800字（非空白字符）
   - 突出成效、讲清楚内容即可
   - 优先保留成果和数据，精简过程描述

4. **格式要求**：
   - 纯文本格式，不使用markdown
   - 一级用数字+顿号，二级用数字+括号
   - 同级事项用分号分隔，不换行
   - 每个要点简洁明了
   - **不使用三级列表**，用分号在同一行内展开
