# Kaze 12 Prompts(12 个通用提示词库)

> 来源:数字生命卡兹克《都 Agent 时代了,我还是想分享给你这12个我最常用的Prompt》(2026-08-21)
> 定位:**与模型能力无关的通用提示词模板**——适配所有 AI,无需安装任何 Skill,可直接复制使用。

## 自动推荐机制(默认使用方式)

用户提出问题时,先做**意图识别**,命中下表任一场景则主动推荐:

| 用户意图 | 命中信号(举例) | 推荐模板 |
|---------|---------|---------|
| 问清问题/理清困惑 | "我说不清楚""不知道该怎么问""帮我理理思路" | 01 苏格拉底式提问 |
| 学习陌生概念 | "讲讲/解释下/什么是XXX" | 02 双层解释法 |
| 拆解优秀成品 | "这个产品/网页/方案为什么好""想学它的做法" | 03 反向拆解 |
| 深度研究领域 | "深度了解/研究下这个行业/公司/技术/人物" | 04 横纵分析法 |
| 核查说法真伪 | "真的假的""靠谱吗""帮我核查下这个数据/观点" | 05 事实核查 |
| 解决复杂问题 | "怎么办""给个方案""这个问题好难" | 06 专家会诊 |
| 方案打补丁/路径依赖 | "总是修修补补""老办法不管用了""推倒重来" | 07 第一性原理 |
| 常规解法失效 | "试过很多方法都不行""换个思路" | 08 跨领域借解 |
| A/B 抉择犹豫 | "选哪个""好纠结""两个都有道理" | 09 双向钢人论证 |
| 空想型决策 | "要不要做""该不该试""纸上谈兵没用" | 10 最小实验 |
| 自我探索 | "我擅长什么""我有什么天赋""不了解自己" | 11 挖掘隐藏天赋 |
| 人生规划 | "人生方向""五年规划""我该往哪走" | 12 人生设计术 |

**推荐流程**:
1. 命中意图后,先用一句话说明为什么推荐这个模板(点中用户痛点,如"你嘴上问的和真正想表达的可能不是一回事");
2. 给出模板名 + 场景定位;
3. 用户确认后,读取 `references/` 对应文件,把 `【】` 占位符替换为用户的真实信息,输出完整可复制的 prompt(或直接代为执行)。

**推荐话术示例**:
- 「这个问题建议用 **苏格拉底式提问** 帮你理清——你描述的困惑里可能藏着真正想问的问题」
- 「你在两个选项间纠结,用 **双向钢人论证** 能把两边的最强理由都挖出来,答案会更清楚」
- 「想真正学会这个概念,建议用 **双层解释法**:小白版保证听懂,专业版保证深入」
- 「光靠想不会有结果,用 **最小实验** 设计一个 7 天低成本验证,比空想有用」

**多意图时**:一个问题可能命中多个模板(如"学一个新领域顺便核查资料"),推荐 1-2 个最匹配的,让用户选。

## 使用方式(用户主动点名时)

1. 按「场景路由表」定位用户需求对应的 prompt。
2. 从 `references/` 读取对应模板文件,取出 `PROMPT` 区块的原文。
3. 把模板中 `【】` 内的占位内容替换为用户的实际信息。
4. 用户有原始材料(文档、数据)时,一并附上,不限制上下文长度。
5. 直接将替换后的 prompt 作为用户的提问发送给模型(或按需引导用户复制)。

## 使用要点

- **全部可单独复制使用**,不需要任何 Skill,适配所有主流 AI。
- **占位符替换**:所有 `【】` 内容必须替换为用户自己的信息,越具体效果越好。
- **附上原始材料**:用户手上有文档/数据时尽量附上,"这年头,不怕上下文多"。
- **长交互类**(天赋挖掘、人生设计)需要 30 分钟以上的多轮对话,引导用户坚持完成。
- **深度研究类**(横纵分析)建议配合各 AI 产品的深度研究功能使用,效果更佳。
- **自动推荐优先**:与用户直接点名某模板冲突时,按用户点名执行。

## 模板文件约定

每个 `references/` 文件包含:
- **用途**:一句话说明适用场景
- **PROMPT**:完整的可复制提示词(代码块包裹)
- **要点**:关键设计说明与使用提示
